`otter settings` — view and edit otter's settings in an interactive
terminal editor.

## Synopsis

```text
otter conf     [options]
otter settings [options]
```

`conf` is a full alias of `settings`; the two behave identically.

## Description

Opens a two-pane terminal UI: a collapsible tree of settings sections
(`container`, `images`, `settings`, `preferences`) on the left, matching
otter.conf's own layout (see `Configuration`), and the
selected field's current value and description on the right.

Boolean fields toggle immediately on Enter. Every other field opens for
editing in place — press Enter again to commit, or Esc to cancel. Some
fields (`shell`, `container-manager`) are checked against a fixed set of
valid values when you commit; an invalid value is rejected and the field
stays open for editing.

Editing never writes to disk on its own — press `s` to save, or `q` to
quit. If you have unsaved changes, quitting asks you to confirm before
discarding them. Saving always writes your own
`$XDG_CONFIG_HOME/otter/otter.conf` (or `~/.config/otter/otter.conf`),
regenerating it from your current settings — this means any comments or
formatting style in your existing file are not preserved, though the
settings themselves are. It never writes to a system-wide config file,
regardless of `--root`.

## Examples

```sh
otter settings
```

Opens the settings editor.

```sh
otter conf
```

Same as above, using the alias.

## Notes

- A status line is always visible above the keybindings, showing
  `no changes`, `unsaved changes`, or a brief `saved` confirmation after
  a successful write.
- The `s` (save) keybinding is dimmed while there's nothing to save, and
  highlighted as soon as any field is edited.
