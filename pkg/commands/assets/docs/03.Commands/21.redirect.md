`otter redirect` — redirect a command inside the container to run on
the host instead.

## Where this runs

Like `otter-export`, `otter-host-exec`, and
`otter-doctor`, this is not a host command — it's
run **inside** an otter container, via the same container-side `otter`
wrapper (`/usr/bin/otter` inside the container) that dispatches to the
real script at `/usr/lib/otter/scripts/otter-redirect`.

In other words: `otter enter my-box`, then run `otter redirect ...`
from the shell you land in.

## Synopsis

```text
otter redirect add --host-cmd "<cmd>" [--as <name>]
otter redirect remove <name>
otter redirect list
```

## Description

Creates a small wrapper binary inside the container that transparently
runs a given command on the host instead, via `otter-host-exec`. This
is useful for commands that only make sense on the host (e.g. an
`rpm-ostree` host managed by an immutable-distro workflow, or a host
package manager) but that you'd rather invoke by a short, container-side
name than by typing out `otter host-exec ...` every time.

- `add --host-cmd <cmd>` creates the wrapper. `--as <name>` sets the
  name it's created under in the container's PATH; it's required when
  `--host-cmd` is more than one word, and defaults to the command
  itself when it's a single word.
- `add` refuses to create a redirect if `<name>` already resolves to a
  real binary in the container — there's no override flag. Remove the
  existing redirect first (or pick a different `--as`) if you want to
  redefine it.
- `remove <name>` deletes a redirect, but only if it was actually
  created by `otter redirect` — it never touches a file it didn't
  create.
- `list` prints every redirect currently defined in the container, one
  per line, alongside the host command it points to.

## Examples

```sh
otter redirect add --host-cmd flatpak
```

Creates `flatpak` in the container's PATH; running it inside the
container runs `flatpak` on the host.

```sh
otter redirect add --host-cmd "rpm-ostree upgrade" --as rpm-up
```

Creates `rpm-up` in the container, redirecting to a multi-word host
command. `--as` is required here since `--host-cmd` is more than one
word.

```sh
otter redirect remove rpm-up
```

Removes the `rpm-up` redirect.

```sh
otter redirect list
```

Lists every redirect currently defined in the container.

## Notes

- Redirects are per-container: they live at `/usr/local/bin/<name>`
  inside the container's own filesystem, not on the host.
- `add`'s real-binary check is dynamic, not a fixed blocklist — it
  catches any name that would shadow something real, including
  otter's own tooling.
- `remove` has no confirmation prompt: it only ever removes files it
  can verify it created itself, and redefining a redirect is as simple
  as running `add` again.

## See Also

- `otter doctor` — diagnose the health of the

- `otter export` — export an app or binary from
  the container to the host.
- `otter host-exec` — run a command on the host
  from inside the container.
