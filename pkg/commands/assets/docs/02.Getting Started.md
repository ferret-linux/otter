# Getting Started

The fastest path from a fresh install to a working container. It
assumes otter is already installed and a container manager (Podman,
Docker, or nerdctl) is available — see installation.md
if not. For a slower, more explained walkthrough of the same journey
(plus lifecycle management, upgrades, rootful containers, and more),
see beginner-guide.md.

```sh
otter create --image fedora my-fedora-box   # create a container
otter enter my-fedora-box                   # drop into a shell inside it
otter list                                  # see all your containers
otter remove my-fedora-box                  # clean it up when done
```

If you omit `--image`, otter uses the configured default image; if
you omit a name, otter derives one from the image (or falls back to
`my-container`). See otter-create for the full
set of creation options.
