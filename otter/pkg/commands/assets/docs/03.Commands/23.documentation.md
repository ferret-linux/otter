`otter documentation` — browse otter's documentation in an interactive
terminal viewer.

## Synopsis

```text
otter docs
otter documentation
```

This command has no options.

`docs` is a full alias of `documentation`; the two behave identically.

## Description

Opens a two-pane terminal viewer. The tree on the left lists the
documentation sections and pages; the selected page appears on the
right. The documentation is embedded in the `otter` binary, so you can
browse it without a network connection or a local copy of the source
repository. Commands described in the pages may still need network
access, for example when pulling an image or fetching a remote manifest.

Use the up and down arrows to move through the tree; the selected
page's preview updates as you move. Use the left and right arrows to
switch focus between panes. Press Enter on a section to expand or
collapse it, or on a page to focus its preview. With the preview
focused, use the up and down arrows to scroll. Press `q` to return to
the shell.

## Examples

```sh
otter docs
```

Opens the documentation viewer at its guide page. Moving through the
tree updates the preview; pressing Enter on a page moves focus to the
preview so you can scroll it.

```sh
otter documentation
```

Same as above, using the full command name instead of the alias.

## Notes

- The tree includes section headings and pages. The preview changes as
  you move the selection, so Enter is only needed to expand a section
  or move focus to a page's preview.
- Because the docs are embedded at build time, the content shown
  always matches the exact `otter` binary you're running, even if your
  local clone of the repository is out of date.
