`otter restart` — restart an otter-managed container environment.

## Synopsis

```text
otter rbt     [options] [container...]
otter restart [options] [container...]
```

`rbt` is a full alias of `restart`; the two behave identically.

## Description

Restarts the named container(s), or every otter-managed container with
`--all`. Internally this simply calls stop followed by start for each
container — there is no separate "restart" primitive in the underlying
container manager. Because of this, `restart` works on containers in
any state: on an already-stopped container it effectively just starts
it.

## Options

| Flag      | Alias |
| --------- | ----- |
| `--all`   | `-a`  |
| `--root`  | `-r`  |
| `--force` | `-f`  |

## Options Explained

### `--all`, `-a`

Restart every otter container instead of specific names.

### `--root`, `-r`

Restart rootful containers.

### `--force`, `-f`

Force the stop phase instead of a graceful stop.

## Examples

```sh
otter rbt my-box
```

Restarts `my-box`.

```sh
otter restart my-box
```

Same as above, using the non-aliased command name.

```sh
otter rbt --all
```

Restarts every rootless otter container.

```sh
otter restart --all --root --force
```

Force-restarts every rootful otter container, skipping the graceful
stop phase.

## Notes

- Wraps `otter stop` and `otter start` internally.
- Works on both running and stopped containers — on a stopped
  container it simply starts it.
