# Installation

Otter is currently distributed from source. Build it locally with the
steps below.

## Prerequisites

- **Go** 1.27.3 or newer (the minimum declared in `go.mod`).
- **One of**: [Podman](https://podman.io/),
  [Docker](https://www.docker.com/), or
  [nerdctl](https://github.com/containerd/nerdctl). Otter needs one
  of these installed and working; it auto-detects whichever is
  available unless told otherwise (see
  `Configuration`).
- A `make`-capable build environment (GNU Make).

## Building from source

Clone the repository and build the binary with `make`:

```sh
git clone https://github.com/ferret-linux/otter otter
cd otter/otter
make build
```

This produces a binary at `./bin/otter`, built with `CGO_ENABLED=0`
for the host's `GOOS`, and embeds the current git commit and build
timestamp into the binary (visible via `otter --version`).

### Installing

```sh
make install
```

By default this installs to `$HOME/.local/bin/otter`. To install
system-wide:

```sh
sudo make install PREFIX=/usr/local
```

`DESTDIR` is also honored for staged installs (e.g. packaging),
following the usual GNU convention:

```sh
make install DESTDIR=/tmp/pkgroot PREFIX=/usr
```

To remove an installed binary:

```sh
make uninstall
```

(Respect the same `DESTDIR`/`PREFIX`/`BINDIR` you used for
`install`.)

## Other useful Makefile targets

| Target          | Purpose                                        |
| --------------- | ---------------------------------------------- |
| `make vet`      | Runs `go vet` only.                            |
| `make fmt`      | Runs `go fmt` across the module.               |
| `make lint`     | Runs `golangci-lint`.                          |
| `make lint-fix` | Runs `golangci-lint` with `--fix`.             |
| `make clean`    | Removes the built `./bin/otter` binary.        |

## Verifying the install

```sh
otter --version
otter --help
```

The first run also checks whether a supported container manager is
available; if none is found, otter prints instructions to install
one.
