# Documentation Guide

This guide helps you choose where to start and how to browse the
documentation in `otter docs`. The names below match the entries shown
in the viewer; they are not links, so select them in the left pane.

## Choose a starting point

- **Installation** — check prerequisites and install Otter.
- **Getting Started** — create, enter, check, and remove a first
  container in a few commands.
- **Beginner Guide** — follow a slower walkthrough of the everyday
  workflow, including upgrades and rootful containers.
- **Commands** — look up command syntax, options, and examples.
- **Concepts** — understand how images, configuration, host sharing,
  security, and container lifecycle behavior work.
- **Tutorials** — follow task-based guides for services, IDEs, GPUs,
  exports, custom images, and other workflows.
- **FAQ & Troubleshooting** — look up common errors and recovery steps.
- **Caveats & Considerations** — understand limitations and tradeoffs.
- **Choosing Your Tool** — decide whether Otter fits your use case.

## Browse in the terminal

Use the up and down arrows to move through the tree; the selected
page's preview updates as you move. Use the left and right arrows to
switch between the tree and the document. Press Enter on a section to
expand or collapse it, or on a page to move focus to its preview. When
the preview has focus, use the up and down arrows to scroll. Press `q`
to return to the shell. The document is embedded in the Otter binary, so
you can browse it without a network connection. Some tasks described
here, such as pulling images or fetching a remote manifest, do need
network access.

Within a page, references such as `Configuration` or `SSH Access to
Containers` name another entry in the viewer. Select that entry in the
tree to read its preview. Use a command's own help or the matching page under
**Commands** when you need the complete syntax for a specific command.
